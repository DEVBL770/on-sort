# On sort — appli iPhone (Expo)

Version native d'On sort : carte Apple Plans (rotation, inclinaison), GPS, photos Wikimedia, agenda Que faire à Paris.

## Lancer sur iPhone avec Expo Go (depuis un PC avec Node.js)

```
git clone -b expo-app https://github.com/DEVBL770/on-sort.git on-sort-app
cd on-sort-app
npm install
npx expo install react react-native react-native-maps expo-location @react-native-async-storage/async-storage
npx expo start --tunnel
```

Puis scanner le QR code avec l'appareil photo de l'iPhone (Expo Go installé).

Tarifs et horaires indicatifs. Photos : Wikimedia Commons (auteur et licence affichés). Agenda : Que faire à Paris (Ville de Paris).
