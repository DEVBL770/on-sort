# On sort

Prototype de l'appli **On sort** : trouver une sortie en famille à Paris et en Île-de-France (dimanches, jours fériés, vacances).

- Site : publié avec GitHub Pages depuis la branche `gh-pages`.
- Photos : chargées depuis Wikimedia Commons par le navigateur, avec l'auteur et la licence affichés dans chaque fiche.
- Tarifs et horaires : indicatifs, à vérifier sur le site de chaque lieu.
